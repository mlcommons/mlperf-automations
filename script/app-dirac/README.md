# app-dirac

Builds [DIRAC](https://gitlab.com/dirac/dirac.git) — a relativistic quantum-chemistry program.

## Usage

```bash
mlcr app,dirac,hpc --quiet
```

## Test

The `tests` block is intentionally empty. Requires registration/license; the repository is not publicly clonable. A best-effort build recipe is in `run.sh`; enable a real test once validated in CI.
