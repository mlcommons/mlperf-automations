# app-fhi-aims

Builds [FHI-aims](https://gitlab.com/fhi-aims/FHIaims.git) — an all-electron numeric-atom-orbital electronic-structure code.

## Usage

```bash
mlcr app,fhi-aims,hpc --quiet
```

## Test

The `tests` block is intentionally empty. License-restricted; the repository is not publicly clonable. A best-effort build recipe is in `run.sh`; enable a real test once validated in CI.
